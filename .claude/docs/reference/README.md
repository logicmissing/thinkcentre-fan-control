# reference/

Raw ground-truth material for this project — specs, decompiled type
libraries, official API references, real extracted source from working
examples. Anything that belongs here is meant to be **grepped for a
specific answer**, not read start to finish.

Per `.claude/rules/coding-conventions.md`'s verification-first habit:
before writing code or documentation that depends on how a third-party
system behaves, check it against something in this folder first, rather
than guessing or relying on general knowledge about a similar-but-different
system.
