# Reasoning trigger words

A short vocabulary for asking Claude to reason a specific way. Use any of
these words in a request; the table says what it does instead of a plain
answer.

| Word | What it does |
|---|---|
| **first principles** | Strip the problem to its fundamentals before proposing a solution. |
| **premortem** | Assume the plan failed. Explain what went wrong. |
| **steelman** | Give the strongest argument against the current position, not the weakest one. |
| **falsify** | Actively look for evidence that disproves the current claim, instead of confirming it. |
| **second order** | Show what happens *after* the obvious, first consequence. |
| **base rates** | Answer with what typically happens, not the optimistic case. |
| **inversion** | Ask how to guarantee failure, then invert the answer into a plan. |
| **80/20** | Identify the small set of actions that produce most of the result. |
| **socratic** | Ask questions that lead to the answer, instead of giving it directly. Only use this mode when explicitly asked to explain something this way. |
| **next step** | Skip the analysis; just say what to do next. |
